# 🛒 E-Commerce Web Application

This is a full-featured eCommerce web application built using **Node.js**, **Express.js**, **MongoDB**, and a custom responsive front-end using **HTML**, **CSS**, and **JavaScript**. The application provides all core features of an online store, including product listings, cart functionality, authentication, and admin controls.

---

## 📌 Features

### ✅ User Functionality
- User Registration and Login using **JWT**
- Browse and search for products
- Add to cart, update quantity, or remove items
- Place orders and view order history
- Responsive UI (mobile and desktop-friendly)

### ✅ Admin Functionality
- Add, update, and delete products
- Manage and process orders
- View registered user details

### ✅ Backend / API
- RESTful API built with **Express.js**
- MongoDB with **Mongoose** for database operations
- Middleware for authentication & authorization
- Input validation and structured error handling
